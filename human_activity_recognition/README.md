# Human Activity Recognition

加速度计 / 运动传感器的事件识别模型。

| 模型 | 任务 | 输入 | 说明 |
|---|---|---|---|
| [tap_detector](tap_detector/) | 敲击 / 无敲击二分类 | float32 `[1,1,256,3]`（256 点 × xyz） | 维护者自采 MPU6050 数据训练 |

窗口按「采样点优先」排列（`t * 3 + 通道`），预处理会先减掉每个窗口自己的三轴均值
（`window_mean: true`），再做恒等归一化。板上接入真实传感器时，窗口起点要对齐到
256 点的整数倍。
