# Predictive Maintenance

旋转机械 / 工业振动的故障诊断模型。

| 模型 | 任务 | 输入 | 说明 |
|---|---|---|---|
| [kfupm_1dcnn](kfupm_1dcnn/) | 不平衡 / 不对中 / 正常三分类 | int8 `[1,4096,4]` | KFUPM 四通道振动数据集，跨转速测试 |

输入是四路同步径向振动（V1 / H1 / V2 / H2，两个测点的正交对），25.6 kHz 下 4,096 点
= 160 ms。`ai_spec.yaml` 的逐通道标准差取自训练的 global 归一化模式；换传感器或
改变安装位置要重新标定。
